# Docking validation program closeout v1

The current REDOCK, CROSSDOCK, and APODOCK validation campaign is closed as a
validation layer. Historical raw evidence and manifests remain immutable and
are referenced by the Docking Capability Profile v1.

- APODOCK v1.2 was not created because current evidence does not justify it.
- No new docking benchmark is prioritized by this closeout.
- Parameter search is not an implicit continuation of validation.
- Future docking work requires a new, explicit scientific question and a new
  protocol decision.

Existing workflows remain available as historical, diagnostic, or capability
checks; this closeout does not delete or rewrite them.

# Molecular Discovery Phase 1 closeout

Phase 1, Computational Molecular Discovery, is closed enough to transition to
the Biolab Experimental Feedback phase. It is not described as wasted work.

## Lineage

- MOLDISC-001–005 established generation and solubility evidence boundaries.
- MOLDISC-006 established fail-closed target preparation.
- MOLDISC-007–012 established the JE2 lineage and bounded docking.
- MOLDISC-013–015 established geometry and source provenance boundaries.
- MOLDISC-016 established robustness through a bounded megacampaign.
- MOLDISC-017 established receptor-state megacampaign evidence.
- MOLDISC-018 established reciprocal cross-docking characterization.

The lineage created validated infrastructure, evidence boundaries, candidate
identities, source lineage, docking capability characterization, experimental
hypotheses, and failure semantics.

## Decision boundary

MOLDISC-018 reported four of four any-pose primary successes, two of four
rank-1 successes, zero sampling failures, and two misranked near-native poses.
That is sufficient for the current bounded E2 capability profile. Additional
pose-basin, reranking, clustering, rescoring, ensemble, conformer, or PDB
work would remain E2 and would not answer the primary open question.

The current lineage has reached diminishing decision-relevant returns from
additional E2 work. The next major scientific gain requires physical evidence.
The next meaningful project action is therefore an external experiment:
protocol, quote, samples, BIOEXP-001 commissioning, and a real result.

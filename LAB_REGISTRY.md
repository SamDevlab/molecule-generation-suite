# Lab registry

The default registry contains the existing Molecule, Fuel, Combustion,
Thermal, Propulsion, Metal, Degradation, Docking, Pharma and Knowledge Labs,
plus v2.2 application foundations: Electrochemistry, Battery, Corrosion,
Mechanics, Surface, Transport, Composite, Ceramic, AdditiveManufacturing,
Aerospace, Automotive and Energy. Application foundations require conditions
and do not invent engine-backed evidence.

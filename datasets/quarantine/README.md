# Legacy dataset quarantine

This directory is a non-destructive quarantine boundary. No legacy file is
moved here automatically. Manifests generated by
`research_os.legacy.scan_legacy` may reference files under `Biolab/` and
`formolecular/` by path and hash.

Default policy: `eligible_for_training = false` until provenance, license,
units, conditions, split strategy, and independent validation are reviewed.

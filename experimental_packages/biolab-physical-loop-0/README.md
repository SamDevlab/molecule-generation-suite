# Biolab Physical Loop 0

This package freezes the first vendor-neutral physical bridge for the Biolab
vertical. It contains the complete A0B0/A1B0/A0B1/A1B1 panel and contracts for
future external measurements.

The package is an experiment request, not a result. No member is labelled as a
lead, winner, predicted best, recommended, or expected to work. Procurement
and synthesis are deliberately represented only by readiness statuses.

`BIOEXP-001-SOLUBILITY-2X2` is the primary milestone. Its protocol is
incomplete until an external laboratory supplies the missing conditions and
quote/protocol details. `BIOEXP-002-PROTEASE-2X2` is planning-only.

Any result example carrying `TEST_SYNTHETIC` and `NOT_SCIENTIFIC_EVIDENCE` is a
fixture and cannot be promoted to E4. Real results must pass the identity,
protocol, provenance, conditions, report, and artifact-hash gates.
